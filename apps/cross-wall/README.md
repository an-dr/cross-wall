# cross-wall

The crossWall desktop app, built as the `cross-wall-app` executable. It composes the bones engine, draws every screen with egui, and owns settings, logs, the image cache, and installation.

Depends on `cross-wall-sources`, `cross-wall-library`, `cross-wall-apply`, and `bones-kernel` from `vendor/bones`. Run it with `cargo run -p cross-wall`.
