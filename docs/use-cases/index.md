# Use cases

A use case states one goal and what the actor observes when it worked. A change that breaks one is a breaking change.

Fields: **Actor**, **Goal**, **Flow**, **Success**.

Actor: **Wallpaper user**, one person with several computers who collects photos and sets them as the desktop background.

Areas: [setup](setup.md), [browse](browse.md), [library](library.md), [apply](apply.md), [install](install.md).

Not offered: scheduled rotation, per-monitor wallpapers, a tray icon, MSI or distribution packages, macOS, Linux ARM64, accounts or a server, and the transport that copies the sync folder between computers.
